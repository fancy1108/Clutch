# Clutch v1.2.3 — Product Snapshot

**Released:** 2026-07-12  
**Tag:** [v1.2.3](https://github.com/fancy1108/Clutch/releases/tag/v1.2.3)  
**Changelog:** [CHANGELOG § 1.2.3](../../CHANGELOG.md#123---2026-07-12)

## What this version is

Clutch v1.2.3 is a **macOS + Windows** patch that ships the native **handoff flow (D34)** — `/handoff` PTY command injection with polling-based handoff file pickup — along with Design session isolation fixes, TUI injection reliability improvements for Mimo/Claude/Codex/CodeBuddy CLI agents, and CLI detection robustness (system daemon filtering, ChatGPT.app Codex fallback paths).

## Shipped capabilities

- All v1.2.2 capabilities (including Windows Design Preview on v1.2.2).
- **Handoff flow (D34):** Native `/handoff` PTY command, temp handoff file scanning via OS temp directory, general prompt injection with polling guard, multi-turn chat history in summarization, deferred source lane collapse.
- **Design session isolation:** `DesignWorkspace` keyed with `sessionRunId`, lane transcripts cleared on runId change, canvas state fully reset on switch.
- **Design Chinese text fix:** `ensureCharset` for iframe `srcDoc`.
- **Multi-CLI injection:** `mimo-cli`, `codex-cli`, `claude-cli`, `codebuddy-cli` added to PTY ready detection and warmup strategy.
- **CLI detection:** System daemon filtering, system-wide PTY count, ChatGPT.app fallback paths for Codex CLI.
