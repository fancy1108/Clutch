# Clutch v1.4.2 — Product Snapshot

**Released:** 2026-09-28  
**Tag:** [v1.4.2](https://github.com/fancy1108/Clutch/releases/tag/v1.4.2)  
**Changelog:** [CHANGELOG § 1.4.2](../../CHANGELOG.md#142---2026-09-28)

## What this version is

Clutch v1.4.2 is a **patch** on top of v1.4.1: it makes the chat feed and the Changes panel **scale gracefully to large file lists** (hundreds of files no longer flood the DOM or the LLM context), adds a **non-Git workspace hint** so the Changes tab explains itself when the workspace isn't a repo, and ships **reliability fixes** for Design (black-and-white pages, modify never versioning, orphan-session pruning wiping folders) and Chat (auto-compaction folding visible history too early). No workflow / MCP / worktree surface changes.

**Windows:** MSI/NSIS installers included — `windows-build.yml` runs on every `v*` tag, so patch releases ship Windows too.

## Shipped capabilities

- **Lighter chat feed on big file lists:** `FilesChangedChips` now collapses when there are more than 8 files — first 8 chips + a total count + a "Show all (N)" expander; the expanded view lives in a 220 px scrollable container. A 593-file change set no longer produces 593 chips in the chat.
- **Changes panel groups, collapses, and filters:** The right-side Changes tab now groups files by top-level directory (collapsible headers with counts), collapses all groups by default when there are more than 50 files, and shows a filter input when there are more than 20.
- **Non-Git workspace hint:** When the active workspace is not a Git repository, the Changes tab shows a bilingual "Not a Git repository" notice instead of a bare "No uncommitted changes"; `/api/workspace/changes` now returns an `is_git_repo` flag.
- **`run_terminal_cmd` efficiency guidance:** The tool description now nudges the agent toward shell globs / `find -maxdepth`, ripgrep over `grep -r`, and stat-first for "can I delete X?" questions — so it stops running 17 GB recursive grep to answer simple questions.
- **Design pages no longer black-and-white:** Canvas cards and sidebar thumbnails load the sidecar-served preview URL (`src=`) instead of oversized `srcDoc` iframes that froze at the pre-Tailwind paint; Pick-element mode still uses `srcDoc`.
- **Design modify records versioned rounds:** "modify" now records `_r1`, `_r2`, … like add/duplicate/delete instead of overwriting `_r0.html` in place.
- **Orphan-session pruning guarded:** `prune_orphan_session_dirs` skips entirely when the registry is empty but artifacts exist, and never touches folders modified within 24 hours.
- **Chat auto-compaction no longer folds too early:** The trigger now estimates the *current* context fill (visible message text + system-prompt allowance) against the model window (default 100k, `CLUTCH_COMPACT_THRESHOLD` override) instead of comparing a fixed 15k threshold against lifetime cumulative tokens.
- All v1.4.1 capabilities (Agnes 3.0 Flash, D68 reply style) and v1.4.0 capabilities (HTTP MCP, Settings FM-01…05, Worktrees D32, Orchestra send-immediate, Assigned-Agent node engine).
