## What this version is

Clutch v1.4.0 turns the Settings / MCP / CLI surfaces from stubs into working product: Streamable HTTP MCP (D57), command policy and local trust, native scans for Codex and other CLIs, git worktree isolation (D32 / FM-11), and a quieter Terminal Orchestra (`@` send dispatches immediately; FM-06 withdrawn). Empty shells (Planner/Executor, Event channel, Notify user, parallel Proceed/Hold) are gone.

---

## Shipped capabilities

### HTTP MCP (D57)

- Settings → MCP registers any Streamable HTTP URL; optional API key in Env.
- HTTPS 401 without a key can fall back to `mcp-remote` browser OAuth (same path for Figma and other remotes). No vendor-only button.

### Settings modules (FM-01…05)

- **General:** default workspace (restored on launch), confirm-before-stop, app version.
- **Local trust:** one-time confirm before enabling an MCP server; user-authored SOPs skip this (D58).
- **Command policy:** allow / ask / deny shell patterns; deny fails the tool with no Allow card.
- **CLI scans:** Codex plus Aider / CodeBuddy / Antigravity / Rivet / Ollama / ZCode read native local files (or `ollama list`).

### Worktrees (FM-11 / D32)

- Enable isolation from Chat **+**; Agent cwd stays under `.clutch/worktrees/<id>`.
- Parallel trees, footer Worktree picker, Files/Changes follow the selected tree.
- Merge lands on the main checkout; Discard removes the tree. No unsolicited `git commit`.

### Terminal Orchestra

- `@CLI` send confirms immediately (D66/D67). Same CLI reuses the live lane; a fifth *new* agent still queues in the backend only (no queue strip UI).
- Overview can save dispatch records as a user SOP (FM-07). Chat handoff drafts remain (FM-08).

### Workflow canvas

- Node engine follows **Assigned Agent** (no extra Node engine dropdown, D65).
- SOP list shows the full name; click a row to use it (D58).

### Other

- Memory search (FM-12), Design visual review (FM-16), interpreter error cards (FM-17), validation strip (FM-18).
- Workspace `MEMORY.md` (`记住：` / `remember:`), verification notes, memory poison filter.
- Withdrawn: FM-13 Event channel, FM-14 Notify user, FM-15 parallel Proceed/Hold, FM-19 Planner/Executor Settings, FM-06 confirm card / queue / Complete drafts.
