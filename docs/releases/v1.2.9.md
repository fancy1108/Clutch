## What this version is

Clutch v1.2.9 ships **Coding-mode image paste** (Chat + Terminal OrchestratorBar) with try-first multimodal vision and OCR/palette fallback, **click-to-preview** for workspace paths and attachment thumbnails, plus Design Spec→UI / handoff polish (D39–D41) and **path-stable workspace ids** so sidebar history cannot orphan (D43).

---

## Shipped capabilities

### Coding image paste & preview (D42)

- Paste or attach images from Chat and Terminal **OrchestratorBar** (not xterm).
- **Chat LLMs:** send multimodal first; on soft refuse / API reject, retry with local OCR/palette analysis.
- **Local CLI agents:** persist images under `.clutch/attachments/` and inject `@path` / `[file: path]` (no base64 on argv); OCR only after CLI refusal.
- Terminal uploads share the same attachments directory (`*` gitignore + size-triggered GC).
- Clickable paths / `[file:]` / fences open App preview; **images open as media**; Terminal Overview shows attachment thumbnails.

### Design handoff & Spec flow (D39–D41 / D40)

- Spec→UI continuous by default; soft-confirm is opt-in (`CLUTCH_DESIGN_SPEC_CONFIRM=1`).
- Preview Demo → Coding stepped handoff; Generate is deterministic HTML→React (no LLM redraw).

### Workspace history stability (D43)

- Workspace ids derived from resolved path hash; migrate legacy random ids; atomic `workspaces.json` writes; refuse ephemeral authorize in default store.

### Other fixes

- Thinking bubble no longer inherits huge image-message height.
- New Design always appears at the top of the sidebar.
- Design iterate overlay clears when the session reaches `ready`.

## Upgrade notes

- No breaking changes from v1.2.8.
- Local OCR text extraction needs a system **tesseract** binary (`brew install tesseract tesseract-lang`); palette analysis works with Pillow alone.
- After install, restart the app so the sidecar picks up vision try-first / attachments routes.

---

## Not included / known limits

- Packaged DMG does not bundle the tesseract binary; OCR remains best-effort when tesseract is on PATH.
- Agnes chat vision may still reject some clipboard `data:` URIs at the API layer — Clutch then falls back to local analysis.
