# Clutch v1.1.1 — Product Snapshot

**Released:** 2026-07-04  
**Tag:** [v1.1.1](https://github.com/fancy1108/Clutch/releases/tag/v1.1.1)  
**Changelog:** [CHANGELOG § 1.1.1](../../CHANGELOG.md#111---2026-07-04)

## What this version is

Clutch v1.1.1 is a **patch release** shipping **Windows interactive PTY** for Terminal Orchestra ([#30](https://github.com/fancy1108/Clutch/pull/30), thanks [@996wuxian](https://github.com/996wuxian)), **macOS / Windows platform chrome split**, font-size preference restore, cross-platform `tauri:dev`, and unified chat workspace spacing. Inherits all v1.1.0 capabilities (Terminal Orchestra, CodeBuddy, OpenCode Zen, Agnes Video, …).

## Shipped capabilities

- **Windows interactive PTY:** WinPTY backend for embedded xterm lanes in Terminal mode ([#30](https://github.com/fancy1108/Clutch/pull/30)).
- **Platform chrome split:** `platform/chrome/*.{macos,windows}.tsx`, shared `navConfig.ts`, [`PLATFORM_MAINTENANCE.md`](../PLATFORM_MAINTENANCE.md).
- **Font size preference:** Settings UI, `data-font-size` persistence, `SettingsSelect` dropdown ([#30](https://github.com/fancy1108/Clutch/pull/30)).
- **Cross-platform dev:** `node scripts/run-tauri-dev.mjs` ([#30](https://github.com/fancy1108/Clutch/pull/30)).
- **Chat workspace polish:** Compact chat layout and 30px right supervision panel gutter on both platforms.
- All v1.1.0 capabilities.
