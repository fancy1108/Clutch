# Clutch v1.2.4 — Product Snapshot

## What this version is

Clutch v1.2.4 is a **macOS + Windows** patch release. It unlocks prototype **Ready mode interactions** inside preview iframes, converts the horizontal round selector into a standard **custom dropdown menu** (aligning with Clutch's footer menus), fixes WebKit/Safari iframe component picking, adds a global fallback log mapper for rounds, and bypasses CORS restrictions in the Playwright scraper to cleanly extract computed CSS variables (such as environmental warm green variables on sustainability platforms).

## Shipped capabilities

- All v1.2.3 capabilities (including native handoff flow).
- **Interactive Ready (Prototype) Mode:** Unlocks hovers, typing, and standard browser events inside preview iframes when not in picking mode (`pointer-events-auto` instead of `pointer-events-none`).
- **Computed CSS Scraper Bypass:** Scraper fallback queries custom properties via `getComputedStyle` on root, body, and top-level container elements (`body > *, body > * > *`). Bypasses CORS blocks on external stylesheets.
- **Tailwind Utility Filtering:** Scraper ignores framework utility variables (`--tw-*`, etc.) to prioritize true brand/theme tokens in LLM generation prompts.
- **Design Round Dropdown menu:** Horizontal scrollable round selector bar converted to custom popover dropdown select menu matching Clutch's standard popup UI menus (supports Escape key and click-outside close).
- **Node sync & component picking fixes:** Consolidated React Flow sync triggers to prevent cards disappearing; forced iframe remounts to bypass WebKit `srcDoc` caching bugs, and added `nodrag nopan` event isolation.
- **Agent Log execution fallback:** Reconstructed step logs for Design rounds by scanning the global process log.
