# Clutch v1.1.2 — Product Snapshot

**Released:** 2026-07-06  
**Tag:** [v1.1.2](https://github.com/fancy1108/Clutch/releases/tag/v1.1.2)  
**Changelog:** [CHANGELOG § 1.1.2](../../CHANGELOG.md#112---2026-07-06)

## What this version is

Clutch v1.1.2 is a **macOS-only patch release** (Apple Silicon DMG + optional in-app updater) adding **MiMo Code CLI** (`mimo-cli`) as a first-class agent with headless routing and Terminal Orchestra `@Mimo` dispatch, promoting **Cursor Agent CLI** (`cursor-agent`) to the recommended Tools list with `@Cursor` dispatch, and shipping Terminal Orchestra / chat UI fixes plus Claude Code CC Switch config repair in Settings.

**Windows:** No new installers for v1.1.2. Windows users stay on [v1.1.1](https://github.com/fancy1108/Clutch/releases/tag/v1.1.1) until the next **minor** release (e.g. v1.2.0, v1.3.0). Patch releases (`1.1.x`) are macOS-only per maintainer release policy.

## Shipped capabilities

- **MiMo Code CLI:** Whitelist + `mimo run --dangerously-skip-permissions` headless routing; prefers curl-installed `~/.mimocode/bin/mimo` over npm wrapper; `@Mimo` in Terminal Orchestra; Settings Models/MCP/Skills scan tab.
- **Cursor Agent CLI:** Recommended tool with brand logo; detection via `cursor-agent` / `agent` (not IDE `cursor` launcher); `@Cursor` Orchestrator dispatch.
- **Claude Code CC Switch repair:** Settings → Models (Claude Code) surfaces broken config paths and one-click repair.
- **Terminal Orchestra fixes:** PTY-only background terminal count; chat thinking bubble height aligned with last user message.
- **Homebrew cask:** `depends_on macos: :sonoma` symbol form.
- All v1.1.1 capabilities (on macOS).

## Not included / known limits (v1.1.2)

- **macOS-only release** — patch versions do not publish Windows MSI/NSIS; next Windows build targets minor releases (1.2.0, 1.3.0, …).
- macOS DMG still **unsigned** (Gatekeeper workaround in INSTALL).
- Homebrew tap `sha256` must be updated after macOS DMG is published (see `scripts/sync-homebrew-tap.sh`).
