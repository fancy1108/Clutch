## Shipped Capabilities

### One-Click Interactive Prototype

Design mode screens can now be previewed as a fully clickable, navigable interactive prototype:

- **Click-to-Navigate:** Buttons and links in the simulator iframe directly navigate to their target screens, with browser-style back/forward history.
- **Dual-Mode System:** Toggle between preview mode (click navigates) and edit mode (click opens context menu for interaction editing) via pencil button in the simulator header.
- **Thumbnail Sidebar:** Scrollable thumbnail cards with mini iframe previews and flow counts replace the old dropdown selector.

### Visual Connection Editor

In edit mode, interactions are visualized and editable:

- **SVG Connection Lines:** Blue dashed lines connect hot zone elements in the simulator to their target thumbnails in the sidebar.
- **Drag-to-Reconnect:** Drag the target circle on any line to a different thumbnail to change the flow target.
- **Drag-to-Create:** Click an unconnected element to spawn a new line, drag to a thumbnail to create the interaction.
- **Scroll-Aware:** Line endpoints follow sidebar scrolling with off-screen arrow indicators.

### IUE (Interaction Understanding Engine)

Backend pipeline that automatically infers navigation flows between design screens:

- 6-stage pluggable architecture (identify → classify → match → score → reason → approve)
- 17 semantic element roles, 5 matching strategies, deduplication and noise filtering
- Role-based inference for buttons without explicit target text (e.g., "Sign In" → Dashboard)

### Interaction Contract & Code Generation

- **Contract Persistence:** All user-edited flows auto-save to `.clutch/design/sessions/<id>/interaction_contract.json`.
- **React Code Generation:** One-click generation of a complete Vite + React 19 + Tailwind 4 project from the contract. Includes HTML→JSX conversion, onClick injection, and full project scaffold.
- **AI Prompt:** Pre-written prompt with contract and code paths for handoff to any AI coding agent.

### Business State Simulation

- Four prototype states: Normal, Warning, Critical, DataOverflow
- Extreme Mode for stress-testing UI with long strings and overflow values
- Multi-viewport matrix (Desktop 1440px, Tablet 1024px, Mobile 390px) with device shells

### Post-Tag Hotfixes (re-released)

Bundled into the re-tagged `v1.2.7` after the first tag had already shipped these same-day fixes:

- **Pick-mode element selection restored** — `UiCardNode` iframe sandbox must keep `allow-same-origin`; an earlier change dropped it, leaving the inline picker script in an opaque origin so `postMessage` could not reach the parent and clicks only selected the whole board.
- **Design Modify iteration page-type lock** — prompt + parser now refuse to change a screen's page type mid-iteration (e.g. login → dashboard).
- **Session history preserved on load failure** — `sessions.json` records no longer get silently deleted when a state-load error occurs.
- **Empty draft dedup is view-only** — deduplication of empty draft sessions never persists deletions back to disk; deletions require the explicit delete action.
- **Prototype toolbar polish** — arrow separator added between the Connections and Code buttons; toolbar right-aligned to match the simulator header.

## Known Limitations

- Connection line accuracy depends on IUE heuristic quality; some manual correction may be needed.
- Drag-to-connect uses mouse events; touch support not yet implemented.
- Code generation covers page-to-page navigation; overlay/modal interactions not yet generated.
- Business states limited to 4 presets; full scenario groups deferred.

---

## Upgrade Notes

- No breaking changes from v1.2.6.
- Interaction contracts saved in `.clutch/design/sessions/<id>/interaction_contract.json` are forward-compatible.
- Generated code requires Node.js 18+ and uses Vite 6 + React 19.
