**Changelog:** [CHANGELOG § 1.2.5](../../CHANGELOG.md#125---2026-07-13)

## What this version is

Clutch v1.2.5 is a hotfix release. It corrects a packaging issue in the PyInstaller sidecar spec configuration where the `src/design/presets` directory containing brand specifications (such as the Claude, Framer, and Linear style templates) was not bundled in the binary, causing them to be unavailable in production app builds.

## Shipped capabilities

- All v1.2.4 capabilities (including Ready mode, computed CSS crawler, custom dropdown menus, sync fixes).
- **Design Presets Packaging Fix:** Bundled the `presets/` directory in the PyInstaller sidecar build (`clutch.spec`) so that system style specs (like Claude, linear, etc.) are available in production app builds.
- **Preset loading validation test:** Added `test_builtin_presets_loading` to design service tests to ensure Claude, linear.app, and framer presets are successfully loaded.
