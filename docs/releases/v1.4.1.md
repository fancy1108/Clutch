# Clutch v1.4.1 — Product Snapshot

**Released:** 2026-09-21  
**Tag:** [v1.4.1](https://github.com/fancy1108/Clutch/releases/tag/v1.4.1)  
**Changelog:** [CHANGELOG § 1.4.1](../../CHANGELOG.md#141---2026-09-21)

## What this version is

Clutch v1.4.1 is a **macOS-only patch** on top of v1.4.0: the built-in **Agnes free models move to the next generation** (3.0 Flash chat, Image 2.5 Flash, Video 2.5 Flash), and the **Clutch Agent default reply style (D68)** now leads with the next action or the answer instead of preamble. No workflow / MCP / worktree surface changes.

**Windows:** No new installers. Stay on [v1.4.0](https://github.com/fancy1108/Clutch/releases/tag/v1.4.0).

## Shipped capabilities

- **Agnes free models:** Built-in catalog is **Agnes 3.0 Flash** (chat), **Agnes Image 2.5 Flash**, and **Agnes Video 2.5 Flash** (720P, OpenAI Videos-compatible). Retired `agnes-2.0-flash`, `agnes-image-2.1-flash`, `agnes-video-v2.0`; saved selections remap to the new ids.
- **Clutch Agent reply style (D68):** Default replies lead with the next action or the answer, skip preamble/closers, and state error cause + fix. Time estimates, `<agent_status>` recaps, and unsolicited images stay out of the default prompt; the full ADHD output skill remains optional via Skills / `read_skill`.
- All v1.4.0 capabilities on macOS (HTTP MCP, Settings FM-01…05, Worktrees D32, Orchestra send-immediate, Assigned-Agent node engine).
