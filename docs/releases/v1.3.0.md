## What this version is

Clutch v1.3.0 completes the self-built **Clutch Agent** chat capability (D1–D54): the agent now has a Grok-/Cursor-aligned **tool trail (D46)**, four clear **permission modes (D27/D54)**, **deliverable intent inference + real image/video generation (D54)**, a **tool-skip harness (D44)** that forces advertised tools to actually be used, and a **plan-approve → execute** bridge so confirmation actually leads to file edits. Sidebar projects/sessions now sort by last chat activity.

---

## Shipped capabilities

### Tool trail detail (D46)

- Verb-group headers use tool families (`Fetched N pages`, `Searched N queries`); `web_fetch` / `web_search` titles show host/query.
- Each step row shows the target URL/query; expanding attaches a truncated result preview.
- **View in Terminal** works for any tool step (not only shell).

### Permission modes (D27 / D54)

- Composer pill is **Agent / Plan / Full / Ask** (Cursor-style order & labels; ∞ / checklist / warning / chat).
- Default **Agent** (`auto_edit`). **Ask** is conversation-only; legacy **Explore** maps to Ask.
- First-run onboarding Permissions step matches the new selectable modes.

### Deliverable intent + real media (D54)

- Chat decomposes the user ask (search / summarize / visualize / present / implement) and infers deliverable kind — users need not name "HTML/图片".
- `generate_image` (configured image model → `.clutch/generated/images/`); `generate_video` tool; auto-calls the configured Agnes (or other) image/video model after a turn that needs media.
- Browser auto-open only for inferred pages; writing `.html` as a fake visual is refused.
- New chat `.md` / `.html` / image dumps at repo root are relocated to `.clutch/artifacts/`.

### Tool-skip harness (D44)

- Live-fact turns (weather/news/URL) answered in prose with zero `tool_calls` trigger one reminder + `tool_choice=required` retry.
- Policy rejects (`web_fetch` on SERP, etc.) no longer count toward the loop fuse.

### Plan approve → execute

- After the user says 确认/批准/按计划, Chat injects an execute reminder + tool-skip nudge so the model must `todo_write` then `apply_patch`/`search_replace` — no more re-asking for confirmation or claiming done with prose only.

### Other changes & fixes

- **Allow network default On (D15):** New installs expose `web_search` by default.
- **Subtask budgets (D10):** Nested explore/implement loops use 16/12 tool-step caps (was flat 8).
- **Background jobs (D11):** Composer bar shows running jobs only; finished jobs seal into the Chat timeline.
- **Shell writes → Changes (no git required):** `run_terminal_cmd` mutations fill `files_changed` / Changes chips even in a non-git workspace.
- **Network soft-cap nudge:** After the web budget, reminds the model to continue write tools; soft-caps at 3 `web_search`/`web_fetch`, hard-caps at 5.
- **Sidebar recent-first:** Projects and sessions sort by last chat activity; reopening an old chat floats it to the top.
- **Usage / Steps (D9 · D22):** Composer + → Usage removed; Overview Session Token Analytics keeps the section with `—` placeholders until provider-true usage (DECISIONS Q-USAGE-1).

## Upgrade notes

- No breaking config changes from v1.2.9.
- New installs default to **Agent** mode and **Allow network** On; existing users keep their prior preference.
- `generate_image` / `generate_video` need a model key configured in Settings → Models (Agnes or other provider); without a key the chat reply states the last step failed and how to fix it.
