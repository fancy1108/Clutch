# Clutch v1.2.2 — Product Snapshot

**Released:** 2026-07-11

**Changelog:** [CHANGELOG § 1.2.2](../../CHANGELOG.md#122---2026-07-11)

## What this version is

Clutch v1.2.2 is a **macOS + Windows** patch that brings **Windows Design Preview / Tauri build parity** up to the v1.2 Design stack, and lands workflow reliability fixes (ZCode flags, agentType validation, canvas JSON banner reasons, `file_exists` path clarity, human-gate approve spam).

**Windows:** Installers ship again (MSI/NSIS). Previous Windows stay-on advice for v1.2.0/v1.2.1 no longer applies after upgrading to v1.2.2.

## Shipped capabilities

- All v1.2.1 capabilities (including sidecar hotpatch client D37 on macOS).
- **Windows Design Preview** path resolution, process-tree stop, manifest lock retries.
- **Windows Tauri** `tauri:dev` / `beforeBuildCommand` Node wrappers (no bare `uv` required).
- **ZCode CLI** flag compatibility (#50 / #51).
- **Agent config** strict `agentType` validation + tool mismatch warning (#54).
- **Workflow editor** canvas-incompatibility reasons in JSON banner (#55).
- **`check(file_exists)`** FORBIDDEN + resolved-path logs (#53).
- **Human gate** serialized approve / HITL debounce (#52).
