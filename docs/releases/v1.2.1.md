# Clutch v1.2.1 — Product Snapshot

**Released:** 2026-07-11

**Changelog:** [CHANGELOG § 1.2.1](../../CHANGELOG.md#121---2026-07-11)

## What this version is

Clutch v1.2.1 is a **macOS-only patch** fixing Chat / Design / Models regressions from v1.2.0, and shipping the **sidecar hotpatch client (D37)** so future backend-only fixes can land without bumping app semver. **This release’s bugfixes still ship as a full in-app update** — 1.2.0 installs do not yet have the hotpatch client.

**Windows:** No new installers. Stay on [v1.1.1](https://github.com/fancy1108/Clutch/releases/tag/v1.1.1).

## Shipped capabilities

- **Chat fix:** Unwrap `{content, reasoning_content}` from HTTP LLM complete before sanitize/display.
- **Design:** Footer Model/Agent/Workflow visible after Terminal Orchestra; design-system preset picker restored on welcome.
- **Models:** Connection test prefers `GET /models` probe (avoids Agnes long-TTFT false failures).
- **Sidecar hotpatch (D37):** Silent download → **Update ready** chip → confirm → restart orchestrator only. See [`docs/UPDATES.md`](../UPDATES.md) §5.
- All v1.2.0 capabilities on macOS.

## Not included / known limits (v1.2.1)

- No hotpatch **package** published for the 1.2.0→1.2.1 bugfixes (clients on 1.2.0 lack the channel).
- Sidecar hotpatch v1 is **macOS-only**; SHA256 from manifest (minisign follow-up).
- macOS DMG still **unsigned** (Gatekeeper workaround in INSTALL).
