# Clutch v1.2.0 — Product Snapshot

**Released:** 2026-07-10  
**Tag:** [v1.2.0](https://github.com/fancy1108/Clutch/releases/tag/v1.2.0)  
**Changelog:** [CHANGELOG § 1.2.0](../../CHANGELOG.md#120---2026-07-10)

## What this version is

Clutch v1.2.0 is a **minor release** shipping **Design mode (D36)** — a workspace session for generative UI prototyping on an infinite canvas — plus **ZCode CLI** as a first-class routed agent, Design Agent Log per-step model/token tags, and generate/iterate reliability fixes. As a minor bump, it restores **Windows MSI/NSIS** installers alongside the macOS DMG (after macOS-only patch v1.1.2).

## Shipped capabilities

- **Design mode (D36):** Header `Coding | Design`; session `mode: design`; welcome → canvas (spec → UI) → NL iterate; Design.md / URL / image references; built-in Clutch design-system preset; Approve → React codegen → Send to Coding; `design-to-code` template.
- **Design Agent Log:** Thinking + Execution on the canvas; each step shows **status**, **model**, and **token** tags (history-safe when switching models mid-session).
- **ZCode CLI (`zcode-cli`):** Headless `zcode -p --mode yolo --json`; Terminal Orchestra `@ZCode`; resume; recommended Tools card ([#43](https://github.com/fancy1108/Clutch/pull/43)).
- **Epicode memory workflow** template + MCP guide ([#22](https://github.com/fancy1108/Clutch/pull/22)).
- **Reliability:** Design Sketching/hydrate fixes, blank-HTML fallback, session folder naming, macOS single Dock icon, Windows CI mimo scan fix.
- All v1.1.2 capabilities (MiMo Code CLI, Cursor Agent CLI, …).

## Not included / known limits (v1.2.0)

- macOS DMG still **unsigned** (Gatekeeper workaround in INSTALL).
- Windows installers may still need hardware smoke ([#23](https://github.com/fancy1108/Clutch/issues/23)).
- Homebrew tap `sha256` must be updated after macOS DMG is published (see `scripts/sync-homebrew-tap.sh`).
- Design mode does not replace Figma collaboration; no cloud share of Design sessions.
