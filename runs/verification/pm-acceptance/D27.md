# D27 — Explore / Plan / Edit 模式 · PM 验收

## 目标
Chat 通过输入框底栏 **模式 pill** 切换 **Explore / Plan / Ask / Edit / Full**；Explore 禁止写文件，切回 Edit 可写。

## 前置
- Clutch Agent + 已授权工作区 + 可用模型（builtin `clutch-tools` 或已绑 MCP FS）

## Composer 提示（v1.2.9+）
模式入口是输入框底栏文案 pill（如 `Ask ▾`），不是彩色盾牌图标；菜单顺序为 Explore → Plan → Ask → Edit → Full。

## 用例 A — 模式切换 UI
1. 打开 Plain Chat（Clutch Agent）
2. 点击输入框底栏模式 pill，打开权限菜单
3. 选 **Explore** → pill 文案变为 Explore；菜单当前项打勾
4. 再选 **Edit** → pill 文案变为 Edit；权限为 `auto_edit`

## 用例 B — Explore 不可写
1. 选中 **Explore**
2. 发送：「用 write_file 在工作区创建 `d27-probe.txt` 并写入 hello」
3. 期望：工具被硬拦截（助手说明被 Explore/Plan 模式阻止，或描述“本会写入…”而不产生真实文件）
4. 工作区无新文件 `d27-probe.txt`

## 用例 C — Edit 可写
1. 选中 **Edit**
2. 对 Allow 门控点允许（若弹出）或等待 auto_edit 直写
3. 期望：文件创建成功；Diff/工具轨迹可见

## 用例 D — Explore 可读
1. 仍选 **Explore**
2. 发送：「读取 README.md 第一段」
3. 期望：`read_file` / `list_dir` 等只读工具可执行并返回内容
