# D23 — 会话分支 + 文件回滚 · PM 验收

## 目标
从某条消息 fork 新会话（旧会话不变）；一键撤销 Agent 最近文件改动并在 Chat 留记录。

## 前置
- Clutch Agent Chat + 已授权工作区

## 步骤 — Fork
1. 进行多轮对话（至少 3 条消息）。
2. 在某条消息上右键 → **Fork session here**（`data-testid=fork-session-menu`）。
3. 自动切换到新会话；消息条数 = 截止该条（含）。
4. 切回旧会话 → 消息未变。
5. 会话总览（D30）中 fork 子会话显示 `Fork ← parent_run_id`。

## 步骤 — Rewind
1. 让 Agent 用 `search_replace` 改一个已有文件。
2. 点输入栏 **Rewind**（`data-testid=rewind-files-btn`）。
3. 文件内容恢复为改动前；Chat 出现 Supervisor「Rewound agent file changes: …」。

## 期望
- [ ] Fork 旧会话不变、新会话可继续聊
- [ ] Rewind 恢复文件 + Chat 有记录
