# D38 — Hub 可信状态（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 步骤

1. 打开 **Settings → MCP**（Clutch Tab）。
2. 确认页面顶部 **不再** 出现「开发中 / Under development」横幅。
3. 注册一个坏命令服务器，例如：
   - Name: `Broken Probe`
   - Transport: `stdio`
   - Endpoint: `clutch-mcp-definitely-missing-bin-xyz`
4. 点该行 **Test connection**。
5. 预期：红色可读错误（含 `not found` / `Failed` 等），**不是**笼统灰点。
6. （可选）对 `local-fs` 或已装好的 filesystem 服务器点 **Test connection** → 显示「已连接 — N 个工具」且 TOOLS 数字更新。
