# D16 — 跨会话记忆 · PM 验收

## 目标
Settings 开/关 Memory；会话 A 记下偏好 → 会话 B 仍遵守；可一键清除。

## 前置

## 步骤
1. Settings → General → **Cross-session memory** → **Memory: On**（`cross-session-memory-toggle`）。
2. 会话 A：让 Agent 调用 `remember_preference`（如「提交说明用中文」）或明确说「记住：提交用中文」。
3. 新建会话 B，不问重述，让 Agent 写 commit 说明 → 应倾向中文。
4. Settings → **Clear memory**（`clear-cross-session-memory`）→ 条目清零。
5. 关 Memory → `remember_preference` 应报错提示先开启。
