# D17 — Hooks Pre/Post tool · PM 验收

## 目标
项目/用户 `hooks.json` 配置 PreToolUse/PostToolUse 拒绝规则；违规时 Chat 可见原因。

## 前置
- Clutch Agent + 工作区

## 步骤
1. 在用户偏好目录或项目 `.clutch/hooks.json` 写入：
   ```json
   { "PreToolUse": [{ "tool": "search_replace", "action": "deny", "reason": "No edits in demo" }] }
   ```
2. 让 Agent 调用 `search_replace`。
3. Chat 工具轨迹显示 **failed**；详情含 `Hook PreToolUse blocked search_replace: No edits in demo`。

## 期望
- [ ] Hook 拒绝有明确原因
- [ ] Chat 可见（工具步骤 failed）
