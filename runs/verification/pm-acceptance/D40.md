# D40 — Chat 已绑 MCP 可见（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 步骤

1. Chat 选择 **Clutch Agent**（非工作流）。
2. 若 Agent **未绑** Hub 服务器：输入栏上方出现 **「绑定 MCP」**（`chat-mcp-bind-cta`）→ 点开进入 Agent Manager。
3. 在 Agent Manager Module 4 勾选 `local-fs`（或任一 Hub 服务器）并保存。
4. 回到 Chat：徽章变为 **`N MCP · ~M`**（`chat-mcp-badge`）；点击弹出服务器名列表。
5. 取消绑定后再看：徽章回到「绑定 MCP」。
