# D40 — Chat 已绑 MCP 可见（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## Composer 提示（v1.2.9+）
MCP 入口在输入框 **+** 菜单 → **Session tools** 分区（不再常驻输入框上方）。

## 步骤

1. Chat 选择 **Clutch Agent**（非工作流）。
2. 若 Agent **未绑** Hub 服务器：打开 **+** → **绑定 MCP**（`chat-mcp-bind-cta`）→ 进入 Agent Manager。
3. 在 Agent Manager Module 4 勾选 `local-fs`（或任一 Hub 服务器）并保存。
4. 回到 Chat：再开 **+**，项变为 **`N MCP · ~M`**（`chat-mcp-badge`）；点击弹出服务器名列表。
5. 取消绑定后再看：菜单项回到「绑定 MCP」。
