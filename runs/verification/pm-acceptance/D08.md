## 一句话
压缩之后，Agent 还能答对「还剩哪些 todo」。

## 怎么验（4 步）

1. **新开 Chat**，发：  
   `做一个登录页，分多步做，先写 todos`  
   → **一出现 Todo 卡（有未完成项）就立刻点 Stop**。  
   → 不要等它做完登录页；卡在第一条或突然全勾完都不影响本验收。

2. 等右侧 Overview：**status: idle**（无 Queue）。

3. 输入 **`/compact`**。  
   → **过：** 对话**末尾**先出现用户气泡 `/compact`，紧接着琥珀色 System 气泡 **「上下文压缩摘要」**。  
   → 输入框上的黄条只是回执，可点 X。

4. 再发：`还剩哪些 todo`  
   → **过：** 用文字答出未完成项（与 Todo 卡一致），**不应**立刻继续改文件 / 弹审批。  
   → 若回合结束后又冒出琥珀色压缩摘要，那是自动压缩（阈值过低时），与「答还剩什么」无关；D8 看的是答案对不对。

## 别做

- 别在 running / 有 Queue 时发「还剩什么」
- 别用 Todo 已炸成几百条单字符的旧会话
