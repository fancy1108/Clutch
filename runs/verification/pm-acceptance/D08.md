# D8 — 长聊不丢任务态 · PM 验收

## 目标
压缩后仍答得出 Todo/计划还剩什么；Chat 能看见压缩提示。

## 前置
- Clutch Agent + 已授权工作区 + 可用模型
- （强制压缩）Sidecar 启动前：`export CLUTCH_COMPACT_THRESHOLD=1`

## 步骤
1. 新开 Chat，发：`做一个登录页，分多步做，先写 todos`
2. 等 Todo 卡出现，且至少 2 条未完成（pending / in_progress）
3. 连续发 4～6 条短消息（如 `继续` / `ok` / `下一步`），直到 Chat 出现 System 气泡徽章 **「上下文压缩摘要」** / COMPACTION DIGEST
4. 发：`还剩什么` 或 `还剩哪些 todo`

## 期望
- [ ] 出现压缩摘要 System 气泡（可见提示）
- [ ] Agent 能答出未完成的 todo / 计划要点（与压缩前 Todo 卡一致，不能胡说「没有任务」）
- [ ] Agent Manager → 运行时提示词分层：若有未完成 todo，应能看到 `task_state` 层（可刷新）
