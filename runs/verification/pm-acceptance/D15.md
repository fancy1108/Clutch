## 目标

Clutch Agent 内置 `web_search` 可搜网页并引用来源；Settings 可关联网。

## 前置

- Clutch Agent + 已授权工作区 + 可用模型

## 用例 A — 默认关闭

1. **Settings → General** 确认 **Allow network / 允许联网** 为 **Off**
2. 发送：「用 web_search 搜 React 19 新特性并总结」
3. 期望：工具不可用或返回 disabled 说明；无 `web_search` 在 builtin 列表

## 用例 B — 开启后搜索

1. 打开 **Allow network**
2. 重开 Chat 或新回合，发送：「搜一下 DuckDuckGo 是什么并给出来源」
3. 期望：`web_search` 返回带 title/url/snippet 的 JSON；助手摘要含来源

## 用例 C — 关闭后不可用

1. 关 **Allow network**
2. 再发搜索请求
3. 期望：可读错误，不再调用外网
