> ROADMAP 保持 ❌ 直至本用例人工通过。

## 目标

Clutch Agent 内置 `web_search` 可搜网页并引用来源；Settings 可关联网。

## 前置

- Clutch Agent + 已授权工作区 + 可用模型

## 用例 A — 默认开启可搜

1. **Settings → General** 确认 **Allow network / 允许联网** 为 **On**（新安装默认开；旧偏好若为 Off 请手动打开）
2. 重开 Chat，发送：「搜一下 DuckDuckGo 是什么并给出来源」
3. 期望：`web_search` 返回带 title/url/snippet；助手摘要含来源（不得空口拒答）

## 用例 B — 关闭后不可用

1. 关 **Allow network**
2. 再发搜索请求
3. 期望：工具不可用或返回 disabled 说明；无 `web_search` 在 builtin 列表

## 用例 C — 空答强制重试

1. Allow network On；问天气类问题
2. 若模型先空口拒答，Terminal 应出现 Tool-skip nudge，随后出现 `web_search`/`web_fetch`
