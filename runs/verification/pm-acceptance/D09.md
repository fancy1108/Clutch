# D9 — 运行可控 · PM 验收

## 目标
Chat 内可见：停止、继续、死循环熔断提示、用量/步数。

## 前置
- Clutch Agent + 已授权工作区 + 可用模型
- （可选强制熔断）Sidecar：`export CLUTCH_LOOP_FUSE_FAILURES=3`

## Composer 提示（v1.2.9+）
输入框默认只显示 **+ · 模式 pill · 发送/Stop**。用量入口在 **+** 菜单 → **Usage**（`data-testid=chat-run-stats`），不再常驻输入框上方。

## 用例 A — 停止 / 继续
1. 新开 Chat，发一条会跑工具的任务（如「列出工作区文件并总结」）
2. 工具开始执行时点输入栏 **Stop**（确认对话框点确定）
3. 期望：出现 Supervisor「已停止…」气泡；输入栏出现 **Continue**
4. 打开 **+** 菜单 → **Usage**（`chat-run-stats`）可见 Steps / tok（熔断时带 fuse 标注）
5. 点 **Continue**
6. 期望：发出继续提示并重新跑一轮（status=running → 有回复）

## 用例 B — 熔断（可选 / 难复现时看自动化）
1. 若能构造连续工具失败（如指向不存在的路径反复改文件），期望：助手回复含「Loop fuse / 死循环熔断」；Continue 出现；**+ → Usage** 可显示「熔断 / fuse」
2. 自动化已覆盖：见下方 pytest

## 用例 C — 用量可见
1. 任意一轮工具执行中或结束后，打开 **+** 菜单可见 **Usage** `Steps n/m · ~N tok`（不必精确等于供应商计费）
2. 点击该项打开 Usage dashboard（见 D22）
