# D35 — 导入能力包 · PM 验收

## 目标
导入 zip/目录（skills + hooks.json + mcpServers 片段）；注册后可用；可卸载。

## 前置
- Settings → Skills 页

## 步骤
1. 准备目录结构：
   - `skills/my-skill/SKILL.md`
   - `hooks.json`（可选）
   - `mcpServers.json`（可选）
2. Settings → Skills → **Import capability pack**，输入目录绝对路径（`capability-pack-import-path`）。
3. 列表出现新 pack；Skills 扫描可见新 skill。
4. 点 **Uninstall** → pack 从列表移除；skills 挂载撤销。

## 期望
- [ ] 导入后 skills/hooks 生效
- [ ] 可卸载
