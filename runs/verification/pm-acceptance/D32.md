# D32 — Worktree 隔离试验 · PM 验收

## 目标
可选「在隔离 worktree 里改」；主工作区不被脏改；可合并或丢弃。

## 前置
- 已授权 **git 仓库** 工作区
- Clutch Agent Chat 模式

## Composer 提示（v1.2.9+）
启用入口在 **+** → **Session tools** → **Enable worktree**；启用后才在输入框**上方**出现紧凑状态条。

## 步骤
1. 打开输入框 **+** 菜单 → **Enable worktree**（`data-testid=enable-worktree`）。
2. 点击启用 → 输入框上方出现紧凑 worktree 条（`data-testid=worktree-active-chip`），显示分支与路径；**+** 菜单中启用项消失（已 active）。
3. 让 Agent 在隔离目录写文件（如创建 `wt-test.txt`）。
4. 主仓 `git status` 仍干净；worktree 条显示 **dirty**。
5. 点 **Discard**（`data-testid=discard-worktree`）→ 副目录删除，主仓仍干净。
6. 再次启用 worktree，改文件后点 **Merge** → 主仓出现合并提交/改动。
