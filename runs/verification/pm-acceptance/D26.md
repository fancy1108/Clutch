# D26 — 长任务监视（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。基于 D11 后台任务加强。

## 前置

- Clutch Agent Chat；可触发 `run_terminal_cmd` 且 `background=true`

## 步骤

1. 让 Agent 启动一条**注定失败**的后台命令（如 `sleep 1 && false` 或 `exit 1`）。
2. 任务结束后，Chat 时间线出现 **Supervisor** 气泡：`[Monitor] Background job failed: …`
3. 输入栏上方 **Background jobs** 条显示 Failed；同时出现红色 **toast**（`bg-job-failure-toast`）约 4 秒。
4. （可选）成功结束的任务应出现 `[Monitor] Background job finished: …`
