# D31 — 计划行内批注 · PM 验收

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 目标

计划卡每步可留评论；点 **Revise** 时批注进入修订 payload，Agent 据此改计划。

## 前置

- Clutch Agent 触发 `propose_plan`（多步任务）

## 用例

1. 计划卡 pending 时，每步下方有 **Comment on this step…** 输入框
2. 在第 2 步填「改用 OAuth」；底部可填总评或留空
3. 点 **Revise**（仅需任一步或底部有文字即可启用）
4. 计划卡标为 revised，步骤旁显示批注；Agent 收到含 `Step 2: …` 的反馈并重新 `propose_plan`
