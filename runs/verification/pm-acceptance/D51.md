# D51 — Chat ↔ Terminal 同步（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 前置

- 工作区已授权；Chat 用 **Clutch Agent**（或任意会跑 `run_terminal_cmd` 的会话）
- 可选：已配置 ≥1 个 CLI Agent（有 Chat/Terminal 切换时体验更完整）

## 步骤

1. 让 Agent 执行一条 shell（例如「在工作区跑 `echo D51_SYNC_OK`」），等待工具步骤出现。
2. 在气泡步骤条展开后，点 Shell 步骤旁的 **「在 Terminal 查看」**（`data-testid=chat-view-in-terminal`）。
3. 预期：
   - 右侧栏切到 **Terminal** 页签并打开；
   - 若有匹配的 `[CHAT] Step …run_terminal_cmd…` 日志行，该行高亮（`terminal-log-highlight`）并滚入视野；
   - 若本机有 CLI Agent 且当前是纯 Chat 会话：工作区切到 **Terminal mode**，并 focus 当前/主 lane。
4. （可选）若本回合有子任务卡：点子卡上的 **在 Terminal 查看**，同样切到 Terminal 侧栏。
