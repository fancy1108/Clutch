# D20 — Clutch Agent 忙时消息排队（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 前置

- 工作区已授权；Chat 选择 **Clutch Agent**（plain LLM / MCP，非 CLI Terminal 模式）
- 发送一条会触发多步工具或较长推理的消息（如「列出 src 下所有 py 并总结」）

## 步骤

1. Agent 进入 **running**（输入栏显示 Stop / Steps 计数）时，再发送 **2 条**不同内容的 follow-up（如「顺便查 README」「最后给三条建议」）。
2. 输入栏上方出现 **待发送消息** 列表；每条左侧有 **队列 #1 / #2**（英文 `Queue #n`），右侧可 **移出队列**。
3. 当前回合结束后（status 回到 idle），队列 **按顺序自动发送**；第二条在第一条处理完后再进入 running。
4. 排队期间点 Stop：队列应 **清空**，不会随后续 idle 自动发送。
