# D30 — 会话总览看板（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 前置

- 同一工作区至少 **2 条** Chat 会话历史（可先发两条不同消息生成）

## Composer 提示（v1.2.9+）
入口在输入框 **+** 菜单 → **Session overview / 会话总览**（`data-testid=session-overview-toggle`），不再常驻输入框上方。

## 步骤

1. 打开输入框 **+** 菜单 → **Session overview / 会话总览**。
2. 列表展示各会话标题、所属项目，以及状态徽章：**Running / Done / Idle**（看板 `session-overview-board`）。
3. 当前会话高亮；点击另一条会话 — 应用切回该 `run_id` 并加载历史消息。
4. （D23 fork 父子标识可后续验收；本项仅看板 + 点回。）
