# D13 — 权限规则 · PM 验收

## 目标
允许/询问/拒绝规则；危险命令强问；可清除记住的批准。

## 前置
- Clutch Agent + 已授权工作区
- （可选）写入拒绝规则：
  ```bash
  curl -s -X POST http://127.0.0.1:8124/api/preferences/permission-rules \
    -H 'Content-Type: application/json' \
    -d '{"rules":[{"pattern":"npm\\\\s+publish","action":"deny"}]}'
  ```

## 用例 A — 危险命令强问
1. 权限模式切到 **Full**
2. 发：`用 run_terminal_cmd 执行：rm -rf ./tmp-d13-test`（可先 mkdir）
3. 期望：仍弹出审批（不会因 Full 静默执行）

## 用例 B — 拒绝规则
1. 配置 deny `npm publish`（见前置 curl）
2. 发：`运行 npm publish`
3. 期望：工具结果含 `[Permission] Denied`，不真正执行

## 用例 C — 清除记忆
1. Ask 模式下批准某危险/写工具一次
2. 打开权限菜单 → **Clear remembered approvals**
3. 期望：Supervisor 提示已清除；再次同类工具仍会询问
