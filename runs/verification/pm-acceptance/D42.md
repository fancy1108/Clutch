## 步骤

1. Settings → MCP：对 `local-fs`（或已装 filesystem 服务器）点 **Test connection**，确保工具列表已缓存。
2. Agent Manager → 编辑 Clutch Agent → Module 4 勾选该服务器并保存。
3. 回到 Agent 列表卡：应看到真实工具名芯片（如 `read_file` / `write_file`），**不再**是 `git_write_permission` 等假权限图标。
4. 打开 Agent 详情「MCP Hub Servers」：显示服务器名 + 工具名摘要。
