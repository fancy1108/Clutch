# D21 — ignore rules + strict sandbox（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 前置

- 工作区已授权；Chat 选择 **Clutch Agent**
- 工作区根目录存在 `.gitignore`（含 `secrets/` 或 `*.env`）或 `.clutchignore`

## 步骤

1. 在工作区创建 `secrets/key.env`（已被 ignore）与 `src/app.py`（可见）。
2. 让 Agent 执行 `list_dir` 或 `grep TOKEN` — **secrets/** 与 `*.env` 不出现在结果中。
3. 让 Agent `read_file secrets/key.env` — 返回可读错误（路径被 ignore）。
4. 打开 **Settings → General → Strict sandbox**，开启严格沙箱。
5. 让 Agent 执行 `run_terminal_cmd` 含 `cd ../` 或绝对路径 `/etc/...` — 失败并说明严格沙箱原因。
