# D34 — 前台转后台 · PM 验收

## 目标
长命令前台执行中可一键转入后台（对标 Grok Ctrl+B）；转入后仍可继续聊天，任务出现在 D11 后台列表。

## 前置
- Clutch Agent + 已授权工作区
- Chat 模式（非 Terminal Orchestra）

## 步骤
1. 让 Agent 前台跑长命令（如 `run_terminal_cmd` 不带 `background=true`，命令 `sleep 25 && echo DONE`）。
2. 输入栏上方出现 **Foreground command running** 条（`data-testid=foreground-shell-bar`）。
3. 点 **Move to background**（`data-testid=move-fg-to-background`）。
4. 前台条消失；**Background jobs** 出现 running 芯片（`data-testid=bg-job-…`）。
5. 立刻再发一条消息（如 `1+1=?`）→ Agent 可继续回答，不必等 sleep 结束。
6. Chat 出现 Supervisor 提示「已转入后台」。

## 期望
- [ ] 转后台后可继续对话
- [ ] 任务在 D11 后台条可见
- [ ] Kill / View output 仍可用
