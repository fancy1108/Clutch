# D18 — Chat 斜杠命令（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 前置

- 工作区已授权；Chat 打开任意会话（最好已有若干轮对话以便测 `/compact`）

## 步骤

1. 在输入框键入 `/`，预期弹出命令面板（`slash-command-picker`），顶部有 `/plan` `/compact` `/todos` `/help`，下方为 Skills。
2. 点 **`/plan`**（或输入 `/plan` 回车）：权限模式变为 Plan；出现 notice（`slash-command-notice`）。
3. 点 **`/todos`**：若本会话有 Todo 卡则滚动聚焦；否则 notice 提示尚无清单。
4. 在较长会话点 **`/compact`**：若消息 >5 条，Chat 出现压缩摘要气泡且 notice 报 compacted；过短则 notice 说明不足。
5. 点 **`/help`**：notice 列出可用命令。
