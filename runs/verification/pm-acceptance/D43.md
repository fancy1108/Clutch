# D43 — MCP Resources（PM 点验）

> ROADMAP 保持 ❌ 直至本用例人工通过。

## 前置

- 有一台暴露 `resources/list` 的 stdio MCP（可用自测 mock；或 filesystem 若暴露 file resources）
- 或跑自动化：`uv run pytest tests/test_mcp_resources_d43.py -q`

## 步骤（真机）

1. Settings → MCP → 注册/选中带 Resources 的服务器。
2. 点 **Browse resources** → 列表出现 URI/名称。
3. 点 **Pin for Chat** → 顶部出现「已固定到 Chat」。
4. Chat 选 Clutch Agent，问固定内容相关问题（如 mock 的 `RESOURCE_TOKEN_ORANGE`）→ Agent 能引用固定正文。
5. Unpin → 后续回合不再注入。
