# D22 — 用量看板 · PM 验收

## 目标
本局 token/工具步数可点开查看；历史 session 列表展示各 run 用量，与 D9 实时条一致。

## 前置
- Clutch Agent + 已授权工作区 + 可用模型
- 侧栏至少 1 条历史 Chat session（可选）

## 用例 A — 本局用量 + 看板
1. 新开 Chat，发一条会跑工具的任务（如「列出工作区根目录文件」）
2. 输入栏上方可见 `Steps n/m · ~N tok`（`data-testid="chat-run-stats"`）
3. **点击**该用量条
4. 期望：弹出 **Usage dashboard**（`data-testid="usage-dashboard"`），顶部显示本局 steps/tok 与 D9 条一致
5. 再点关闭或用量条，看板收起

## 用例 B — 跑一轮后数字增加
1. 记下看板中本局 steps/tok
2. 再发一条会触发至少 1 次工具的消息
3. 期望：D9 条与看板本局行 steps/tok **均增加**（不必精确等于供应商计费）

## 用例 C — 历史 session 用量
1. 打开看板，表格列出近期 session（标题 + 日期 + Steps + ~tok）
2. 当前 session 行高亮；切换侧栏其它 session 后，对应用量字段来自历史记录（若该 session 曾跑过工具）
